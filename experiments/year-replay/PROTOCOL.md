# One full year, accelerated paper replay

Period: 2025-09-01 inclusive to 2026-09-01 exclusive (365 days). Starting virtual cash 100 USDT, spot, fee 0.001 per side. BTC/USDT and SOL/USDT: both have a full year of actual 1m Binance data locally, plus 5m/15m/1h/4h/1d warmup. KuCoin adapter provides current precision/minimum rules only: this is Binance-price research, not a KuCoin execution reproduction. No live config changes.

Initial baseline uses validated native 5m data for speed. The existing 1m files have incorrect datetime units; minute-detail validation is a later robustness check, not completed by this baseline. No synthesized minute candles. Continuous native Freqtrade run carries cash and open positions across all 365 days; no daily reset. 5m NFI decisions and 5m execution assumptions. Daily equity includes open holdings. Report every calendar day, fees, adverse equity, forced final exits, and errors.

Bounded improvement: first six months (Sep-Feb) compare two slots versus one slot. Choose only on prefix ending March 1, with higher marked-to-market ending equity and drawdown <=15%; otherwise retain two-slot control (no claim of approval). Freeze before running full year. Full-year control and chosen candidate preserve continuous state; separately report second-half daily-equity changes, noting positions crossing boundary. Period has already been researched; exploratory, NOT untouched holdout or machine-learning training. No optimize-until-green loop, no deployment. Compare buy-and-hold basket after entry/exit fees. If candidate loses or only in-sample improves, reject it.
